Hospital Management System

Django REST FrameworkReact (Vite)JWTPostgreSQL

A role-based hospital management platform (admin, doctor, patient, receptionist) built as part of the Ostad course, modeling 9 relational entities including patients, doctors, appointments, prescriptions, and billing.

  • JWT authentication with automatic silent token refresh and request deduplication on the frontend.
  • Dual-layer role-based access control — queryset-level scoping plus object-level permission checks.
  • Custom DRF exception handler for consistent API errors, plus auto-generated OpenAPI/Swagger docs via drf-spectacular.
  • Reusable React data-fetching hooks, protected/role-gated routing, and a centralized axios client with interceptors.

Multi-Tenant SaaS Project Management Platform

Django REST FrameworkPostgreSQLCeleryRedisDockerJWTReact

A SaaS-style project management platform where multiple organizations manage their own teams, projects, tasks, and activity while keeping their data separate.

  • Multi-tenant architecture with organization-level data isolation.
  • JWT authentication and role-based permissions for admins, managers, and members.
  • Celery and Redis for background notifications, scheduled reports, and activity processing, with Redis caching for frequently requested data.
  • Database optimization through select_related/prefetch_related, indexing on frequently queried fields, and API pagination.
  • OpenAPI/Swagger documentation via drf-spectacular, and a Docker Compose development setup with backend, PostgreSQL, and Redis services.
